GitHub 云端一键编译完整工程

内置完整 Kotlin 原生引擎（OkHttp3 30秒超时免跨域直连大体积书源、Jsoup + GBK + JSONPath + ruleBookInfo 目录二次跳转解析、GitHub Releases 应用内自动更新、物理返回键适配），推送至 GitHub 约 3 分钟自动产出可安装的 app-debug.apk。

1. 修复书源开关误报 & 多节点代理拉取

不再把网页端已开启的自定义 Legado 书源误判为“全部关闭”；支持直连与多路代理拉取远程 JSON，并支持一次粘贴多条 URL 批量导入。

2. IndexedDB 大容量书源存储

突破 localStorage 5MB 上限，导入上千条 Legado 书源包也能秒存不丢失，并自动瘦身保留核心解析字段。

3. 强化原生 Legado 3.0 抓书引擎

新增 ruleBookInfo.tocUrl 详情页转目录页解析、GB18030 转码与 30 秒大文件超时保护。

4. 书架管理 + 沉浸阅读 + OTA 更新

单删/批量删除/置顶、轻点正文沉浸全屏、本地 TXT UTF-8/GBK 识码、GitHub Releases 应用内升级一应俱全。
